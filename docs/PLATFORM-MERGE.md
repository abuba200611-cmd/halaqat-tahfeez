# خطة دمج المنصة (halaqat-tahfeez + masjid-idara)

**الاسم المعتمد (2026-10-13): MOS — نظام تشغيل الجامع (Masjid Operating System).** يُطبَّق على الواجهة وصفحة الدخول ولوحة المطوّر عند النشر الموحّد. لا تُستخدم كلمة «موارد».

القرار (2026-10-12): منصة واحدة مقسّمة أقسام (modular monolith)، أساسها halaqat-tahfeez،
قاعدة بيانات واحدة، ولوحة المشرف العام = **لوحة المطوّر**. نحسّنها لاحقاً.

## المبادئ
- لا توقّف للمعلّمين: كل خطوة إضافية وقابلة للتراجع، والقديم يظل شغّال حتى التحويل.
- مصدر حقيقة واحد: الطالب سجل واحد (لا ربط بالاسم، لا LINK_SECRET بين نظامين).
- كل ميزة جامع = قسم في سجل الميزات يُشغّل/يُطفأ لكل جامع.
- كل طلب يُفحص في الخادم: الدور + ملكية البيانات (جامع/حلقة/ابن).

## المراحل
| # | المرحلة | الخطر على المعلّمين | التراجع |
|---|---|---|---|
| M1 | نقل مخطط الجامع إلى قاعدة الحلقات (جداول جديدة فقط) + سكربت نقل البيانات مع خريطة معرّفات | لا شيء | حذف الجداول الجديدة |
| M2 | نقل كود الجامع داخل تطبيق الحلقات: `/mosque/[id]/...` + APIs، استعلامات مباشرة بدل واجهات الربط؛ الحلقة تُربط بالجامع عبر `halaqahs.mosque_id` مباشرة | منخفض (مسارات جديدة) | إخفاء المسارات |
| M3 | **لوحة المطوّر** `/dev`: الجوامع، الميزات لكل جامع، المستخدمون والأدوار، «عرض كـ» (مسجَّل)، صحة النظام، الاقتراحات، دروس الإيجنت | لا شيء | — |
| M4 | التحويل: masjid-idara.vercel.app يحوّل للمسارات الجديدة؛ القاعدة القديمة للقراءة فقط 30 يوماً | منخفض | إرجاع التحويل |
| M5 | هوية موحّدة: `users` + `memberships` (دور لكل جامع/حلقة/ابن)، صفحة دخول واحدة، زر «تبديل الدور»؛ الحسابات الحالية تُربط تلقائياً بلا تغيير كلمات السر | متوسط (الدخول) | الإبقاء على مسارات الدخول القديمة حتى التأكد |
| M6 | الإيجنت (Haiku 5.5 مقترح) فوق المنصة الموحّدة + ذاكرة لكل جامع + دليل مشترك بموافقة المطوّر | لا شيء | إطفاء الميزة |

## توزيع العمل
- البناء: GLM (وSonnet عند توقّفه).
- المراجعة: Sonnet مختلف عن المنفّذ، تركيز على العزل بين الجوامع.
- القرار والدمج والنشر وتطبيق تعديلات القاعدة: Opus بعد موافقة المستخدم.

## بعد النشر الموحّد — الخطة التالية (اعتمدها المستخدم 2026-10-16، بالترتيب)
1. إشعارات واتساب لولي الأمر (بجانب إشعارات المتصفح).
2. مراسلة داخلية بين المعلّم والطالب وولي الأمر.
3. شريط تقدّم بالأجزاء + تصنيف المراجعة: سبق / سبقي / منزل.
4. زيارات المشرف التربوي وتقييمه للحلقات.
5. الرسوم والاشتراكات (ميزة اختيارية لكل جامع).
6. تطبيق على المتاجر (حالياً PWA).
